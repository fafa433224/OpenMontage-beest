# Storyline Edit — Script Director

Write the script FROM the groups, never before them (FireRed's
GenerateScript required grouped clips; keep that discipline):
- One script block per group, describing only footage that group contains.
- Declare per group: narration text (or explicit no-narration), tone,
  and the emotion beat the group must land.
- If a script template/style reference was provided, mirror its rhythm and
  sentence structure (few-shot style transfer) while keeping facts from
  the actual clips.
- Keep narration speakable at ~2.5 words/second; the asset stage will
  measure real durations and the edit stage will fit clips to them.
