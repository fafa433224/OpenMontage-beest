# Storyline Edit — Scene Director

Turn groups + script into an ordered scene plan:
- Order clips inside each group so the visual order speaks the group's
  script block in sequence (establish -> detail -> reaction/hero).
- Mark hero clips (longer holds) and any clip that must open or close a
  group. Note intended transitions: hard cut inside groups, dissolve (or
  planned AI transition) between groups.
- Do not assign final durations by hand; `storyline_timeline` fits them
  in the edit stage once narration durations are real.
